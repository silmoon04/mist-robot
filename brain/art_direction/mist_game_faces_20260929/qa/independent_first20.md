# Independent QA: first 20 MIST game-inspired face studies

Reviewed all selected group1 through group4 sheets as original complete images using `view_image`, after each final group manifest existed. No assets, prompts or UI files were edited. Both local MIST references were inspected. Catalog observations, manifest approaches and original/repair prompts were compared with the visible designs. A second agent checked that textual adaptation and process claims stayed within the catalog evidence.

**Result: all 20 studies pass the face, layout, crop and expression checks.** All 20 sheets contain exactly five two-eye, one-mouth faces in cells 1 through 5, with cell 6 blank. No text, frames or props were found. No skeptical or concerned mouth reads happy.

The previous Night in the Woods original contained a detached five-pixel cyan fleck beside the left skeptical eye. Two targeted imagegen edits retained it. A fresh built-in generation is now selected, and its canonical file was inspected again at full original scale. The old isolated fleck is absent. The skeptical eyes now share integrated flat-top lids and pupil-edge tapers. A small right-eye taper separates under the cyan threshold, but visually it belongs to the same intentional notch construction as the left eye; it is not judged an accidental floating fragment. This judgement and the threshold evidence are retained in the JSON report.

Every sheet has faint almost-black backdrop variation. This is a literal departure from a uniform flat fill, already disclosed in the manifests. It creates no visible object in the blank sixth cell and is recorded as a limitation. The brightest channel in any sixth cell is 22/255.

The pixel audit only supports the visual inspection. It reads original RGB pixels with G >75, B >75 and G >R +20, checks cyan bounds in each 512-by-512 crop, and looks for isolated components below 100 pixels. It does not infer facial emotion from connected-component counts. Minimum cyan margin across these sheets is 37 pixels. All 20 sixth cells contain zero pixels above this cyan threshold. Only Night in the Woods has a threshold-separated component below 100 pixels; its position at the pupil-edge taper is interpreted visually as intentional.

These are static held expression studies. Continuous animation, transition timing, controller independence and physical-screen readability were not tested.
