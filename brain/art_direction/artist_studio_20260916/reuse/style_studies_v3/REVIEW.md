# Visual review

Approved for comparing two static style directions with the user's reference.
The source sheets and final comparison were inspected directly. Exact manifest,
comparison, reference and source hashes are recorded in `visual_review.json`.

The earlier studies kept too much of the original eye construction. V3 changes
the eye acting. The reference direction uses rounded upper lids joined to lower
cups, open eyes paired with half-lids, and filled upward-looking eyes with dark
pupil cutouts. The second direction pushes squash, uneven eye height and pupil
placement further. These changes remain visible when the glow is ignored.

Quiet thought is the clearest improvement: both versions look upward instead of
relying on a neutral squint. Happy and Delighted use closed smiling or squeezed
eyes. Deadpan has level half-lids. Sad retains a frown and one tear. The cyan,
rounded drawing style is much closer to the supplied image. No activity icons,
clipped artwork or neighboring-cell marks were seen.

Some labels still need adjustment before these become runtime faces. Reference
Curious reads skeptical; More expressive Curious reads puzzled. More expressive
Calm is cheeky and shares most of its eye construction with Playful. The uneven
Listening eyes may also suggest curiosity. These are useful differences to show
in a style comparison, but they are not ten fully settled emotion mappings.

The reference's activity symbols help explain what its faces are doing. This
study deliberately omits those symbols. Static faces alone will not communicate
every task state as clearly.

No new blink, speech-mouth or transition animation was tested. Pupil movement,
small-screen readability and the glow need motion tests before adopting a style
for the phone. This review approves the comparison, not animation readiness.
