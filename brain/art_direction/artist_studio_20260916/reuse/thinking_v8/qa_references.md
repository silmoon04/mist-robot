# Lordicon reference review

Reviewed 2026-09-24 through Lordicon's official documentation and icon pages. Browser screenshots also confirmed the Magnifier's separate lens and handle, the Code icon's two brackets and slash, and the Document's folded-corner silhouette. The screenshots were isolated samples, not a complete motion recording. This pass did not measure their video timings or copy any assets.

- Use a quick action followed by a short readable hold. Lordicon describes interaction motion as starting quickly and slowing down; it can repeat with a delay. For MIST, that supports brisk typing, pencil strokes, and card moves followed by a pause within a 2.2 to 2.8 second phrase. That duration comes from the MIST brief, not from Lordicon. [Animation guidance](https://lordicon.com/docs/animation)
- Separate arrival, ongoing action, and state change. Lordicon's Code icon offers entrance, interaction, morph, and loop states. MIST can likewise use four entrance drawings, sixteen active drawings, and four exit drawings, while keeping the face silhouette and terminal body steady. [Code icon](https://lordicon.com/icons/system/outline/369-code)
- Let a prop's movement explain its function. Lordicon warns that physically implausible or unrelated movement weakens an icon's meaning. The Book icon identifies opening as a morph; the Document page separates arrival from interaction. MIST's reading action should keep the spine fixed, move one page around that spine, and keep text on its own page surface. Those staging details are our application of the guidance. [Animation guidance](https://lordicon.com/docs/animation), [Book icon](https://lordicon.com/icons/system/solid/4092-book), [Document icon](https://lordicon.com/icons/system/solid/56-file-text)
- Keep search motion local to the search object. The Magnifier page separates entrance, interaction, and selection states. For MIST, scan a small document with the lens and hold briefly over a row; place the complete prop below or beside the face with a measurable gap from both eyes. The clearance rule is a MIST requirement rather than a Lordicon specification. [Magnifier icon](https://lordicon.com/icons/system/outline/19-magnifier)

The Code page's introductory sentence describes a calendar despite the icon's code identifier and tags. This review relies on its listed animation states rather than that inconsistent copy. The fetched Document page listed `in-file`, `hover-file-1`, and `hover-file-2`, while the live browser listed `in-reveal` and `hover-pinch`. Both distinguish entrance from interaction; exact state names are not used as implementation requirements.
