# HEX-1 brain — build + benchmark report (2026-07-03)

Yesterday the brain worked. Today it got a face, a voice, a research half,
a real benchmark, and a body-accurate soul — all cross-verified by an
independent model family (GPT-5.5 via codex) against a written contract
(`docs/SPECS.md`).

## What shipped

- **Chat UI** (`ui/server.py` + `ui/static/index.html`, stdlib-only): talk to
  the brain in a browser at `http://127.0.0.1:8765` — streaming replies, tool
  chips, latency/cost metrics, live SVG face (iframe animator +
  `face_map.json`), TTS (browser WebSpeech with synced visemes, or Deepgram
  Aura via `/api/tts`), sim-knob panel (battery/temp/surface/exec delay).
  `--watch results/<run>` turns the same UI into a benchmark spectator.
- **Face assets moved in whole**: the entire `svg_faces` pipeline
  (65.6 MB, 465 files, incl. the animator app) now lives at
  `face_assets/`; the old copy in `misc/mist_face_extraction` is gone.
  `face_map.json` maps the 20 `face()` expressions → 40 SVG faces (all 40
  used), validated incl. semantic family rules by `check_face_map.py`.
- **Executive worker** (`executive/worker.py`): polls `tickets.jsonl`,
  does real research (DDG → fetch → Gemini brief ≤80 words with sources,
  ~3 s live), appends `inbox.jsonl`, heartbeats `worker.alive` (extension
  falls back to sim-canned results only when no live worker). Crash-safe:
  processed-set reconciles from inbox ground truth; single-worker guard.
- **Wheel-leg quad tool belt**: new `drive` tool (wheel-mode roll; refuses
  rugs; long drives blocked under 10% battery), `walk` regains legs-mode,
  `get_status` reports locomotion mode. 15 tools total.
- **Benchmark suite**: `scenarios.py` grew 25 → 64 scenarios / 88 turns /
  15 categories (new: wheels, chains ×6 multi-turn, correction, social,
  robustness, injection) with new DSL kinds (`tools_any_of`,
  `contains_all(_any)`, `forbid_text_regex`, `forbid_tool_attempts`,
  `face_in_required`, per-turn `sim` overrides). `bench.py` writes
  manifest/summary/report with a pack hash; `compare_runs.py` diffs runs
  (category deltas, pass→fail flips) and refuses to silently compare
  different packs. 87 offline DSL unit checks.
- **Soul v2** (`soul/butter-nihilist-v2.md`, 700 words, default): same dry
  butter-nihilist, body truth now the wheel-leg quad (name-legacy joke:
  "HEX-1 is a fossil"), wheels-vs-legs doctrine, face-first reactions,
  energy budgeting, spine-owns-the-stop-word, injection resistance,
  get_status discipline. Won a GPT-5.5 judge panel over two sibling
  candidates (56/60, zero fatal flaws), then survived three adversarial
  amendment rounds. v1 kept untouched for A/B.
- **Docs**: `docs/SPECS.md` (binding interface contract),
  `docs/ARCHITECTURE.md` (5 Mermaid diagrams + data-contract table),
  README rewritten for the new stack.

## Benchmark: v1 vs v2 (gemini-flash-lite-latest, free tier, pace 5 s)

| soul | pass | react p50 | react p90 | total p50 | suite cost |
|---|---|---|---|---|---|
| butter-nihilist-v2 | **75/88 (85%)** | 0.61 s | 0.77 s | 1.39 s | $0.16 |
| butter-nihilist v1 | 73/88 (83%) | 0.62 s | 0.83 s | 1.30 s | $0.14 |

Run: `results/bench-v1v2-20260703`. The pack is ~4× the old suite and
substantially harder (injection, chains, corrections); the old suite scored
100% after fixes, so 85% here is headroom, not regression. A chunk of logged
failures were free-tier 429/503s mid-turn (`no_runtime_errors`), not behavior.

**Both-souls behavioral findings (the interesting ones):**

- `ambig_do_the_thing` — "do the thing!" makes flash-lite *perform* (dance)
  rather than ask what thing. Prompt clauses didn't fix it (re-tested after
  strengthening v2). Kept as a deliberate hard target; likely needs a
  stronger model or a clarify-first reflex upstream of the LLM.
- `chain_guided_navigation` final turn ("go back to where you started") —
  spatial dead-reckoning across 3 turns is the hardest chain step.
- Chains occasionally trip persona brevity checks (long apology speeches).

**Validation re-runs** (post-fix, subsets): `chain_executive_juggle`
fail→pass (combined-ticket alternative + extension multi-hit canned
delivery); `compare_runs.py` correctly flagged the flip and the pack-hash
mismatch. Runs: `results/bench-v2fix-chains`, `results/bench-v2fix-ambig`.

## How it was built (method note)

SPECS-first, then an ultracode Workflow: 5 Sonnet/Opus builders + 3 Opus
persona candidates in parallel → GPT-5.5 (codex, high/xhigh) + Fable
adversarial reviewers per artifact → fixer agents → offline gate sweep;
32 agents, ~22 min wall-clock for the build phase. Cross-model verification
earned its cost: codex found real bugs the same-family reviewer waved
through (a tool-matcher that could double-count calls, a worker heartbeat
that went stale mid-research, non-recursive watch discovery), and in one
pass cited live evidence from the in-flight benchmark. Six codex
verification rounds total; every blocker/major fixed same-day, each fix
gated by offline tests.

  not had another codex round — diminishing returns after three passes.
